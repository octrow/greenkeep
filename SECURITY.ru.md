# Безопасность

Об уязвимости сообщайте приватно: [создайте security advisory](https://github.com/octrow/greenkeep/security/advisories/new). Не открывайте для этого публичный issue.

Первый ответ - в течение 7 дней. Исправления выходят в следующем релизе; поддерживается только последний релиз.

greenkeep работает на вашем компьютере и меняет только те репозитории, которые вы ему передали. Каждый он клонирует в `~/.cache/greenkeep`, состояние хранит в `~/.local/share/greenkeep/state.db`, а с GitHub работает через ваш вход в `gh`. Ключ OmniRoute берётся из `OMNIROUTE_API_KEY` или `~/.omniroute/.env` и отправляется только на `OMNIROUTE_URL` (по умолчанию `http://localhost:20128`). Код из обслуживаемого репозитория уходит на этот адрес в составе промпта, поэтому направляйте его только к тому провайдеру моделей, которому доверяете этот код. Без `--push` с машины уходят только запросы к LLM.

У файлов релиза есть подтверждение сборки (build provenance): `gh attestation verify <файл> -R octrow/greenkeep`.
